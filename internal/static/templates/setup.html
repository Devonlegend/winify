Provisioning a remote Windows server

On the remote host (elevated), enable WinRM once:

Enable-PSRemoting -Force

Then provision it from here (prompts for the password):

winify bootstrap -config config.yaml --remote http://HOST:5985/wsman --user DOMAIN\user
